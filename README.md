# seniorsql-media
Для каждого нового Reels выбирай отдельную спокойную инструментальную композицию CC0. Перед монтажом сверяй название, автора и источник с reels_music.json. Другой фрагмент или аранжировка уже использованной композиции считается повтором. Добавляй запись в реестр вместе с готовым роликом и сохраняй историю после публикации. Мягкие щелчки клавиш звучат только при наборе SQL.
